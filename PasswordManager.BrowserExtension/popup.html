Password Manager Extension - Help

Quick Start

  1. Log in with your master password
  2. Configure your connection mode in Settings
  3. Use the extension on any website with a login form

Connection Modes

🔗 Auto Mode (Recommended)

Automatically tries all connection methods in order: Native → API → localStorage

💻 Native Messaging

Direct local database access. Most secure and works offline. Requires desktop app installed.

🌐 Web API

Connect to your API server for remote access. Requires API server running and configured.

📦 localStorage

Offline mode using cached credentials. Limited functionality, use for temporary access only.

Using the Extension

Autofill Passwords

1. Click the extension icon on a login page
2. Select the credential you want to use
3. Click "Fill" to autofill the form

Generate Password

1. Go to the "Generate" tab
2. Adjust length and character options
3. Click "Generate Password"
4. Copy or fill directly into the page

Troubleshooting

Can't Connect

• Try "Auto" mode in Settings
• For Native mode: ensure desktop app is running
• For API mode: check API URL and server status

Autofill Not Working

• Refresh the page and try again
• Some sites use non-standard forms
• Try manually copying the password
